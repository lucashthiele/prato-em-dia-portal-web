Escolha de como o paciente pode planejar a semana a partir da prescrição — os enums técnicos com nomes de produto.

**O consumidor fornece:** `value` (`RESTRICTED` | `SUBSTITUTIONS_ONLY` | `FREE`), `onChange`, opcionalmente `name` e `legend`.

- Sugira “Seguir o plano” (`RESTRICTED`) na primeira prescrição; o selo “Sugerido” fica nessa opção.
- Nunca mostre o enum ao usuário. Os textos são hipóteses a validar no protótipo com nutricionistas.
