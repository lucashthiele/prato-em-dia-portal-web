Conjunto mínimo de ícones de traço (24px de grade, traço 1.75) usados pelos componentes.

**O consumidor fornece:** `name` e opcionalmente `size` (padrão 20) e `label` (quando o ícone é a única informação).

- Ícones herdam a cor do texto (`currentColor`).
- Para ícones além deste conjunto, use Lucide com `strokeWidth={1.75}`.
