Estado vazio que explica por que não há dados e oferece no máximo uma ação.

**O consumidor fornece:** `title`, `children` (explicação curta), opcionalmente `icon` e `action` (um `Button`).

- “Nenhum paciente ainda” → ação “Adicionar paciente”.
- “Sem semanas registradas” → sem ação: depende do paciente usar o app.
