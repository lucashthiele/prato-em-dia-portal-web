Tile de valor prescrito: meta energética, proteína e outros números definidos pelo nutricionista.

**O consumidor fornece:** `label`, `value` (já formatado em pt-BR), opcionalmente `unit` e `hint`.

- Mostre apenas valores prescritos ou contagens registradas. **Não** mostre percentual de adesão no MVP.
- Use em grade de 2–4 tiles com `space-5` entre eles.
