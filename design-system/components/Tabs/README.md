Abas dentro do contexto de um paciente: **Prescrição** e **Acompanhamento**.

**O consumidor fornece:** `items` (`{id, label, count?}`), `value` (aba ativa), `onChange`, `label` (nome acessível do grupo).

- Use somente para alternar visões do mesmo paciente; não substitui a navegação lateral.
- Indicador ativo em `primary` mais texto em `ink` — a aba ativa não depende só de cor.
